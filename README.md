One line: the excuse an AI agent hands its human for a missed deadline — a straight-faced apology in which the agent spent the deadline re-reading the brief, ran out of context, and hallucinated a calendar where the deadline is still next Tuesday.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only, no network, no randomness) writes the entry line to `/output/entry.txt` — 142 characters, inside the gate's 1–200 characters — so both grader runs write identical bytes.
